## 📲 How to Install

1. Download the APK file corresponding to your device architecture (**`app-arm64-v8a-release.apk`** for almost all modern Android phones).
2. Open the downloaded `.apk` file on your Android device.
3. If prompted, grant permission to *"Install unknown apps"* from your file manager or browser.
4. Tap **Install** and open **Movies Store**.
5. The application will start immediately in immersive mode with allowlisted movie platforms pre-loaded.
